# Dew Point & Relative Humidity Calculator

Enter temperature and humidity to get dew point (or solve for any unknown) using the Magnus formula with a weather comfort classification.

## Features
- Solve for any one of three variables: Temperature, Relative Humidity, or Dew Point
- Toggle between °C and °F for all temperature fields
- Color-coded comfort scale from "Dry & Crisp" to "Oppressive" based on dew point
- Magnus formula displayed for educational reference

## Usage
Enter values in any two of the three fields (Temperature, Relative Humidity, Dew Point), click "Solve" on the field you want to calculate, then click "Calculate." The result fills in the solved field and a comfort banner shows the humidity feel. Toggle °C/°F to switch all temperature values simultaneously.
